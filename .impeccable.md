## Design Context

Developers use colord.dev to try the real colord API, build useful transformation chains, inspect conversions and analyses, and copy executable examples.

The approved visual source is colord.pen. The design is playful, colorful and practical: pale cream/pink/lilac/mint background, juicy translucent glass blocks, subtle inner shadows, soft diffuse sphere reflections and cursor-reactive sheen. Original crown branding uses #2AA0F4 → #FB335F at 52% → #F3D100. Wordmark/headings: Manrope; body: DM Sans; code: DM Mono. Tagline: “Powerful color tools. Ridiculously small.”

Desktop: draggable operation library left, vertical source → transforms → fixed Output → result in the center, output choices on the right; generated code follows the result in the center and scrolls with the page. Mobile: compact operation dropdown anchored to Blocks or the insertion +, touch-friendly handles, native format/type selects, code below result. The dropdown contains transformations only; output is selected in the final Output block. Lightness and Saturation combine positive/negative methods. Output choices are click-only and mutually exclusive. Color pickers use react-colorful. No separate quests, decorative Aa, search, redundant instructions, counts or Playground nav.

Motion should make actions legible: lifted drag preview, insertion targets, layout transitions and copy feedback. Prefer transforms/opacity, honor reduced motion, and keep sliders and typing immediate. Mouse sheen stays subtle, never a continuous animation.

Promo follows the demo: factual adoption panel and benchmark panel, unified prismatic four-fact ribbon. Footer repeats the original brand and useful links. OG uses the approved vivid B export. Facts are snapshots; source/date and benchmark environment are recorded in README/source.
